## 1. PROJECT
- **Name:** ASTRA Academy, an astronaut-inspired XR training simulator.
- **One line:** a standalone-headset VR app in which a cadet learns spacecraft skills through 8 hands-on levels. Every action is logged, scored deterministically and explained in a debrief.
- **User:** junior professionals who are learning (early-career engineers, technicians, trainees): technically literate, new to spacecraft operations. Instructors and demo operators come second. All in-game text follows `docs/content-style-guide.md`.
- **Primary journey:** put on the headset → Hub → pick a level → Briefing → Demonstration → Practice (hints) → Qualification (scored) → Debrief (pass/retry + advice) → next level unlocks.
- **Wow moment:** the cadet fixes a simulated station power fault with their hands. The debrief then says exactly what they did wrong ("you selected Bus A before Bus B") and how to improve.
- **Honesty rule:** an educational prototype. Not astronaut certification and not a real flight procedure. All scenarios are fictional and labelled. No NASA branding implying endorsement.

| L0 | Safety & Calibration | P0 | XR & Interaction |

**MUST (P0) requirements** (full text in `docs/PRD.md` §7): FR-APP-01..05, FR-XR-01..08 (hands only where validated), FR-SIM-01..05, FR-AS-01..04, FR-AI-01, FR-AI-04, NFR-UX-01 (no forced locomotion), NFR-SEC-01/02, NFR-QUAL-01 (reproducible scoring).
**Non-goals:** real flight procedures, microgravity or haptics simulation, multiplayer, full spacecraft systems, a 3D replay system, certification claims.

## 4. CONTRACT v1.3: WHAT YOU MUST KNOW
`CONTRACT.md` is the single source of truth; this is a summary. **If they differ, `CONTRACT.md` wins.**
- **SessionEvent** (§1): `{sessionId, missionId, timestampMs, event, targetId, input, result}`. Use the constants in `Astra.Core.Assessment`: `EventNames`, `InputModality`, `EventResults`, `SystemTargets`. Never retype the strings.
- **Mission file** (§2): `Assets/ASTRA/Content/Missions/<missionId>.json` with `missionId, level, version, title, fictional:true, steps[{stepId, order, instruction, hint, expectedEvent, targetId, critical}]`. IDs: `l0-safety-v1`, `l1-orientation-v1`, `l2-equipment-v1`, `l3-cabin-v1`, `l4-emergency-v1`, `l5-eva-v1`, `l6-robotics-v1`, `l7-restore-power-v1`.
- **Interaction bus** (§3): every interactable calls `Astra.XR.Interactables.InteractionEvents.Raise(eventName, targetId, input)`. Only the LevelController turns these into SessionEvents.
- **Mission runner** (§4): `IMissionRunner.Report(eventName, targetId, input, timestampMs) → StepFeedback {Outcome: Correct | Incorrect | OutOfOrder | Ignored, StepId, Hint}`, using the **step-matching rule** in `CONTRACT.md` §4.
- **Scorer** (§5): `IMissionScorer.Score(mission, sessionId, trace) → SessionResult {passed, completedSteps, skippedSteps, omittedCriticalSteps, sequenceErrors, incorrectActions, completionTimeMs}`. Pass = no critical step omitted. Deterministic.
- **Progress** (§6): `ProgressState`, `IProgressStore` at `persistentDataPath/progress.json`; only L0 unlocked at first.
- **UI** (§7): `InstructionPanel`, `AlarmIndicator`, `PhaseBanner`, `DebriefPanel`, `PauseMenu`, Hub.
- **Level scene** (§8): `Assets/ASTRA/Levels/L<n>_<Name>/`, containing `AstraXRRig` + one `LevelController` + UI + interactables. Seated: targets within 0.7 m, 0.7–1.5 m high, at least 6 cm.
- **Coach** (§9): `ICoachClient`, `OfflineCoach` (always works), `HttpCoachClient` → `POST /api/v1/coach/debrief`. Advisory only; it never changes the score.

## 5. SHARED QUALITY AND SECURITY BASELINE (every stage)
- **SECRETS:** no keys, tokens or passwords in code, scenes, git history, logs, screenshots or prompts. `.env` is git-ignored; `.env.example` holds names only. A leaked key is revoked, not just deleted.
- **DATA:** collect the minimum. No names, emails, raw camera or raw voice. Session logs stay local (`persistentDataPath/SessionLogs`) and are never committed.
- **CONTENT:** fictional scenarios only. No real or export-controlled spacecraft data. No NASA logos or claims of endorsement. Never call completion a qualification.
- **COMFORT:** seated or stationary only. No artificial locomotion, camera shake or forced turns. Pause, recenter and exit are reachable everywhere. Every audio cue has a visual cue and a subtitle.
- **DETERMINISM:** scoring and simulation never depend on frame rate, real time or randomness. AI text never changes state or score.
- **UNITY HYGIENE:** commit every `.meta` file with its asset. Never edit someone else's scene or prefab; make a prefab variant in your own folder instead. Binary art goes through Git LFS. Never upgrade the Unity version or packages yourself (ask the Integration Lead).
- **C# STYLE:** namespaces `Astra.*`. Serialized fields are `[SerializeField] private`; validate them in `Awake` and log a clear error naming the missing reference. No `GameObject.Find` / `FindObjectOfType` in `Update`; no per-frame allocations in hot paths. Unsubscribe from events in `OnDisable`.
- **TESTS:** logic gets NUnit tests. Use the fixtures as test data. A test that was not run does not count.
- **ERRORS:** never swallow exceptions silently. Log them with context, fail safe (pause and show a message), and never crash the headset session.
