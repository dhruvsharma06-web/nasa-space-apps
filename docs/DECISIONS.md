# DECISIONS

Format: `D<n>: decision (why, date)`. Assumptions use `A<n>`.

- **D1:** Unity project lives at the repo root (`Assets/`, `Packages/`, `ProjectSettings/`); non-Unity work goes in `services/`, `scripts/`, `fixtures/`, `docs/`. _Why: Unity expects its root layout; ownership stays per folder._ (2026-11-14)
- **D2:** Mission core (`Assets/ASTRA/Core`) has `noEngineReferences: true`. _Why: scoring must be deterministic and unit-testable without a headset (NFR-QUAL-01)._ (2026-11-14)
- **D3:** Mission content is validated JSON for now; ScriptableObjects can wrap it later. _Why: CI can validate it without Unity._ (2026-11-14)
- **D4:** Gemini goes only through `services/coach-proxy`; the client never holds a key. _Why: NFR-SEC-02._ (2026-11-14)
- **D5:** Binary art and audio go through Git LFS (`.gitattributes`). (2026-11-14)

- **D6:** Unity 6000.3.28f1 (6.3 LTS) for everyone; WebGL uses the PC quality tier. (2026-11-14)
- **D7:** Primary device is a phone in an Irusu Ultra Cardboard-style headset: 3DoF, input = gaze + tap (dwell as accessibility fallback). New input modality `gaze` (CONTRACT v1.4). (2026-11-14)
- **D8:** Levels are generated by the level factory from mission JSON + layout JSON (CONTRACT §2.1); generated scenes are never hand-edited. _Why: 8 levels in 2 days, and new procedures without Unity skills._ (2026-11-14)
- **D9:** Player score 0–100 and Gold/Silver/Bronze are derived from `SessionResult` by `ResultRating` and never change `passed`; the scorer stays the source of truth (CONTRACT §5). (2026-11-14)
- **D10:** The coach is advisory only and offline-first: `OfflineCoach` always works, the AI coach is used when the proxy is reachable, any error falls back silently. (2026-11-14)
- **D11:** A "Demo: unlock all" option exists so judges can reach every level. (2026-11-14)
- **D12:** The camera never moves by itself in gameplay; cinematic camera moves are for the trailer only. (2026-11-14)

## Open (PRD §13)
- **A1:** Primary headset: Irusu Ultra + Android phone (resolved by D7)
- **A2:** Hand tracking is a target, not mandatory; controllers are the guaranteed path
- **A3:** Gemini is optional (P1); the demo must work without it
